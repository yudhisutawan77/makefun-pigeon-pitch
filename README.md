A city pigeon's one-line elevator pitch to investors: Pidge, founder of
Crumb Capital, pitches two million rooftop couriers, zero CAC, infinite
scale — raising just one loaf. A single line, 161 characters.

Run it with `python3 main.py` — it writes the pitch to `$ENTRY_OUT`
(a file path, or `entry.txt` inside a directory).
